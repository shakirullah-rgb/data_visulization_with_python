# Data Visualization with Python 

A beginner-friendly **Data Visualization practice project** using Python, Pandas, and Matplotlib.

## Project Overview

In this project, I worked with a **1000-row sales dataset** and practiced different techniques to explore and visualize data.

##  Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook / Google Colab
- CSV

## Visualizations

The project includes:

- Bar Charts
- Line Charts
- Pie Charts
- Scatter Plots
- Histograms
- Sales Trends
- Product & City Comparisons
- Top 5 Products
- Category Analysis
- Customer Type Analysis
- Payment Method Analysis

##  Dataset

The dataset contains sales information including:

- Order ID
- Date
- Product
- Category
- City
- Customer Type
- Payment Method
- Quantity
- Unit Price
- Discount
- Sales

##  Purpose

The purpose of this project is to practice **data visualization with Python** and learn how to convert raw data into meaningful visual insights.
